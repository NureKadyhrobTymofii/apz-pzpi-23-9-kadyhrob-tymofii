Метою роботи є дослідження архітектури складної програмної системи та аналіз застосованих архітектурних підходів.

3 ОПИС ВИКОНАНОЇ РОБОТИ

3.1 Загальні відомості про систему
Instagram — це соціальна платформа, створена у 2010 році, яка належить компанії Meta Platforms.
Призначення системи:
•	обмін фото та відео; 
•	стрічка новин; 
•	stories та reels; 
•	повідомлення; 
•	рекомендації контенту. 
Система обслуговує сотні мільйонів користувачів щодня, що вимагає високої продуктивності та масштабованості.

3.2 Архітектурний стиль системи
Instagram використовує мікросервісну архітектуру.
Основні принципи:
•	розділення на незалежні сервіси; 
•	взаємодія через API; 
•	горизонтальне масштабування; 
•	кешування; 
•	асинхронна обробка. 
Спочатку система була монолітною, але з ростом перейшла до мікросервісів.

3.3 Основні компоненти системи
Основні частини:
1.	Клієнтська частина
Мобільні додатки (iOS, Android) та веб. 
2.	Backend (сервер)
Обробка запитів, логіка, API. 
3.	База даних
Використовується PostgreSQL для зберігання даних. 
4.	CDN
Доставка фото і відео через мережі доставки контенту. 
5.	Кеш
Використовується Redis для швидкого доступу. 
6.	Черги
Обробка задач через системи типу Apache Kafka.

3.4 Взаємодія компонентів
Процес:
1.	Користувач відкриває додаток 
2.	Запит → сервер через HTTPS 
3.	Сервер обробляє запит 
4.	Дані беруться з кешу або БД 
5.	Контент доставляється через CDN 
Типи взаємодії:
•	синхронна (API) 
•	асинхронна (черги) 
•	подієва (лайки, коментарі)

3.5 Масштабованість та надійність
Instagram використовує:
•	балансування навантаження; 
•	горизонтальне масштабування; 
•	кешування; 
•	реплікацію БД; 
•	CDN; 
•	резервування серверів. 
Це дозволяє системі працювати стабільно навіть при великому навантаженні.

3.6 Приклади програмної реалізації
Для демонстрації архітектурних принципів Instagram наведено приклади програмного коду мовою C#. Вони показують взаємодію клієнта з API та використання кешування для швидкого доступу до даних.
Перший приклад демонструє запит до умовного API Instagram для отримання стрічки користувача:
1 using System;
2 using System.Net.Http;
3 using System.Net.Http.Headers;
4 using System.Threading.Tasks;
5 
6 public class InstagramApiClient
7 {
8     private readonly HttpClient _httpClient;
9

12         _httpClient = new HttpClient();

14         _httpClient.DefaultRequestHeaders.Authorization =

17 
18     public async Task<string> GetUserFeedAsync()

20         HttpResponseMessage response =

22

26     }
27 }
28

Другий приклад демонструє використання кешу для зберігання даних профілю користувача. Такий підхід дозволяє не звертатися до бази даних при кожному запиті та зменшує навантаження на сервер:
1 using System;
2 using System.Collections.Generic;
3 
4 public class UserCache
5 {
6     private readonly Dictionary<int, string> _cache = new Dictionary<int, string>();
7 
8     public void SaveUserProfile(int userId, string profileData)
9     {
10         _cache[userId] = profileData;
11         Console.WriteLine("Дані профілю збережено в кеші.");
12     }
13 
14     public string GetUserProfile(int userId)
15     {
16         if (_cache.ContainsKey(userId))
17         {
18             Console.WriteLine("Дані отримано з кешу.");
19             return _cache[userId];
20         }
21 
22         Console.WriteLine("Дані відсутні в кеші.");
23         return null;
24     }
25 }
26 
27 class Program
28 {
29     static void Main()
30     {
31         var cache = new UserCache();
32 
33         cache.SaveUserProfile(1, "Username: user123, Followers: 1500");
34 
35         string profile = cache.GetUserProfile(1);
36 
37         Console.WriteLine(profile);
38     }
39 }
Наведені приклади демонструють два важливі архітектурні принципи Instagram: взаємодію клієнтської частини із серверним API та використання кешування для підвищення швидкодії системи.

4 ВИСНОВКИ

У процесі виконання роботи було досліджено архітектуру платформи Instagram.
Встановлено, що система побудована на основі мікросервісної архітектури, яка забезпечує гнучкість, масштабованість та незалежність компонентів. Було проаналізовано основні складові системи: клієнтську частину, сервер, бази даних, кеш та CDN. З’ясовано, що взаємодія між компонентами відбувається через API, а також із використанням асинхронних механізмів. Для забезпечення стабільної роботи застосовуються горизонтальне масштабування, балансування навантаження та кешування.
Отже, архітектура Instagram є прикладом сучасної розподіленої системи, яка ефективно обробляє великі обсяги даних і забезпечує стабільну роботу сервісу.

Лістинг В.1 – Отримання стрічки користувача через API (C#)
using System;
using System.Net.Http;
using System.Net.Http.Headers;
using System.Threading.Tasks;

public class InstagramApiClient
{
    private readonly HttpClient _httpClient;

    public InstagramApiClient(string token)
    {
        _httpClient = new HttpClient();
        _httpClient.BaseAddress = new Uri("https://api.instagram.com/");
        _httpClient.DefaultRequestHeaders.Authorization =
            new AuthenticationHeaderValue("Bearer", token);
    }

    public async Task<string> GetUserFeedAsync()
    {
        HttpResponseMessage response =
            await _httpClient.GetAsync("feed");

        response.EnsureSuccessStatusCode();

        return await response.Content.ReadAsStringAsync();
    }
}

class Program
{
    static async Task Main()
    {
        var client = new InstagramApiClient("USER_ACCESS_TOKEN");
        string feed = await client.GetUserFeedAsync();

        Console.WriteLine(feed);
    }
}

Лістинг В.2 – Кешування даних користувача (C#)
using System;
using System.Collections.Generic;

public class UserCache
{
    private readonly Dictionary<int, string> _cache = new Dictionary<int, string>();

    public void SaveUserProfile(int userId, string profileData)
    {
        _cache[userId] = profileData;
        Console.WriteLine("Дані профілю збережено в кеші.");
    }

    public string GetUserProfile(int userId)
    {
        if (_cache.ContainsKey(userId))
        {
            Console.WriteLine("Дані отримано з кешу.");
            return _cache[userId];
        }

        Console.WriteLine("Дані відсутні в кеші.");
        return null;
    }
}

class Program
{
    static void Main()
    {
        var cache = new UserCache();

        cache.SaveUserProfile(1, "Username: user123, Followers: 1500");

        string profile = cache.GetUserProfile(1);

        Console.WriteLine(profile);
    }
}
